# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.4.2] - 2026-10-22

Версия 1.4.1 не вышла: сборка не прошла проверку на сервере. Все изменения 1.4.1 (ниже) входят в эту версию.

### Исправлено

- Выдача и снятие прав на общую папку правят список прав на месте (`SetEntriesInAcl`, способ из документации Windows), а не пересобирают его заново: права, унаследованные от родительской папки, остаются как были и не копируются в явные. Поводом стал тест на сервере сборки, где число записей после выдачи и снятия прав не совпало с исходным.

## [1.4.1] - 2026-10-22

### Добавлено

- Кнопка «Проверить сейчас» в настройках: проверка обновлений лаунчера в любой момент, без галочки и перезапуска; найденное обновление показывается плашкой в главном окне.
- Номер установленной версии лаунчера в левом нижнем углу окна настроек.
- Пункт меню версии «Открыть данные Pilot копии»: настройки и журналы Pilot версии, запущенной в отдельном профиле, открываются в вашем проводнике. Кнопка «открыть журнал» внутри такого Pilot не работает (Windows не открывает папки для программы другого пользователя), пункт её заменяет.
- Доступ к этим данным основному пользователю выдаётся автоматически один раз, при первом запуске копии в отдельном профиле (без запроса Windows).

### Исправлено

- Удаление копии, пока Pilot этой версии запущен: вместо английской ошибки про недоступный файл теперь понятное сообщение «нельзя удалить, пока она запущена», и ничего не удаляется. Раньше удаление успевало стереть часть файлов, включая `manifest.json`, и версия пропадала из списка, оставляя на диске разрушенный остаток, из-за которого повторная загрузка этой версии не проходила. Лаунчер теперь сначала проверяет, что файлы версии никем не заняты, при запуске убирает такие остатки, а установка версии поверх остатка работает.
- Безопасность общих папок: проверка папки смотрела только, не является ли ссылкой последняя часть пути, поэтому путь через ссылку выше (например, `C:\Моя\Ссылка\System32` при ссылке на `C:\Windows`) проходил проверку, а права выдавались на настоящую системную папку. Теперь настоящий путь определяется у системы по открытой папке, любой путь через ссылку отклоняется, права выдаются через тот же дескриптор, а папку данных лаунчера повышенная копия определяет сама. Версия 1.4.0 этого исправления не содержит.

## [1.4.0] - 2026-10-20

### Добавлено

- Лаунчер запоминает размер окна, заданный пользователем (и «развёрнуто»), и открывается с ним.
- «Общие папки» в настройках: папки, которые открываются версиям в отдельном профиле, чтобы открывать в их Pilot файлы основного пользователя. Можно создать папку по умолчанию в «Общих документах» Windows (без запроса Windows) или добавить свою (один запрос Windows). Нельзя открыть системные папки, диск целиком, папки профилей, данные лаунчера и скачанные версии.

### Изменено

- Начальный размер окна увеличен с 860 на 540 до 1100 на 780 (на маленьком экране окно подрезается по рабочей области).

## [1.3.0] - 2026-10-20

### Добавлено

- Редакция myAdmin: версии из центра загрузок и из предварительных, запуск, отдельный профиль, установка в систему, заметки о выпуске (строки «Pilot-myAdmin Desktop»). Блока расширений для неё нет.
- Избранные версии: кнопка-звезда рядом с выбором версии, избранные идут в начале списка и помечены звездой; список хранится в настройках.
- Пункт меню версии «Удалить из системы...»: удаляет установленную в системе версию её деинсталлятором, независимо от копии лаунчера. Если у версии есть и установка, и копия, их можно удалить по отдельности.

### Исправлено

- Удаление копии с данными: если Windows не дала удалить профиль пользователя версии, копия оставалась в списке как «призрак», а повторное удаление падало на несуществующей папке с вводящим в заблуждение «закройте окна Pilot». Теперь список обновляется всегда, повторное удаление не падает, а сообщение говорит, что копия удалена и что осталось (пользователь Windows и профиль), с причиной и кодом ошибки Windows.

### Изменено

- Пункт «Удалить...» переименован в «Удалить копию...» (он удаляет только версию, скачанную лаунчером).
- Версия для сравнения в заметках по умолчанию выбирается по номеру (следующая старшая), а не по месту в списке.
- Диалог «Установить в систему» не говорит о драйвере виртуального диска для myAdmin и больше не утверждает, что myAdmin не затрагивается.

## [1.2.0] - 2026-10-19

### Добавлено

- Проверка обновлений лаунчера при запуске (галочка в настройках, включена по умолчанию) и обновление одной кнопкой: новая версия скачивается с GitHub, сверяется с контрольной суммой релиза, заменяет текущую, и лаунчер перезапускается. Работает для установленной и портативной версии.

## [1.1.0] - 2026-10-19

### Добавлено

- Настройка «Показывать предварительные версии»: сборки из https://pilot.ascon.ru/beta/, которых нет среди выпусков, появляются в списке с пометкой «бета»; заметки о выпуске к ним, скачивание и установка в систему из той же папки.

## [1.0.0] - 2026-10-18

Первый выпуск.

### Добавлено

- Лаунчер версий Pilot для редакций ICE Enterprise, ICE, BIM и ECM: список версий из центра загрузок, скачивание, распаковка без установки, запуск нескольких версий одновременно.
- Изоляция версий отдельными пользователями Windows (свои настройки, логины и кэш у каждой версии); права администратора нужны только для создания и удаления такого пользователя.
- Определение версии, установленной в системе, запуск её от текущего пользователя и копирование для запуска в отдельном профиле.
- Метка версии в заголовке окна запущенного Pilot.
- Удаление версии с вопросом, удалять ли данные версии; проверка свободного места до скачивания; установщики не хранятся.
- Работа без интернета: добавление установщиков из файлов и перетаскиванием, папка с установщиками, скачивание zip для переноса на другой ПК.
- Установка выбранной версии в систему с заменой текущей (настоящим установщиком; при понижении версии сначала удаляется установленная).
- Заметки о выпуске с help.pilotems.com: что нового в выбранной версии и что изменилось между двумя версиями; кнопка доверия корневому сертификату Минцифры, действующему только внутри лаунчера.
- Расширения PilotLookUp и DynamoPilot из релизов на GitHub: установка, обновление и удаление для конкретной версии, одна общая копия на все версии, проверка контрольной суммы.
- Установщик для одного пользователя (`PilotLauncher-Setup.exe`) и портативная версия (`PilotLauncher-portable-win-x64.zip`), один самодостаточный exe без .NET.

### Известные ограничения

- Не проверено на живом ПК: создание пользователя Windows и запуск клиента под ним, связывание профиля с папкой расширений, установка в систему с заменой текущей, установщики ICE, BIM, ECM и старых версий (15.x-25.x). Подробности в [docs/design.md](docs/design.md).
- Файлы не подписаны, Windows SmartScreen может предупредить при первом запуске.
