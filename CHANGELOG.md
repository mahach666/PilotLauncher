# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.1.0] - 2026-10-19

### Добавлено

- Настройка «Показывать предварительные версии»: сборки из https://pilot.ascon.ru/beta/, которых нет среди выпусков, появляются в списке с пометкой «бета»; заметки о выпуске к ним, скачивание и установка в систему из той же папки.

## [1.0.0] - 2026-10-18

Первый выпуск.

### Добавлено

- Лаунчер версий Pilot для редакций ICE Enterprise, ICE, BIM и ECM: список версий из центра загрузок, скачивание, распаковка без установки, запуск нескольких версий одновременно.
- Изоляция версий отдельными пользователями Windows (свои настройки, логины и кэш у каждой версии); права администратора нужны только для создания и удаления такого пользователя.
- Определение версии, установленной в системе, запуск её от текущего пользователя и копирование для запуска в отдельном профиле.
- Метка версии в заголовке окна запущенного Pilot.
- Удаление версии с вопросом, удалять ли данные версии; проверка свободного места до скачивания; установщики не хранятся.
- Работа без интернета: добавление установщиков из файлов и перетаскиванием, папка с установщиками, скачивание zip для переноса на другой ПК.
- Установка выбранной версии в систему с заменой текущей (настоящим установщиком; при понижении версии сначала удаляется установленная).
- Заметки о выпуске с help.pilotems.com: что нового в выбранной версии и что изменилось между двумя версиями; кнопка доверия корневому сертификату Минцифры, действующему только внутри лаунчера.
- Расширения PilotLookUp и DynamoPilot из релизов на GitHub: установка, обновление и удаление для конкретной версии, одна общая копия на все версии, проверка контрольной суммы.
- Установщик для одного пользователя (`PilotLauncher-Setup.exe`) и портативная версия (`PilotLauncher-portable-win-x64.zip`), один самодостаточный exe без .NET.

### Известные ограничения

- Не проверено на живом ПК: создание пользователя Windows и запуск клиента под ним, связывание профиля с папкой расширений, установка в систему с заменой текущей, установщики ICE, BIM, ECM и старых версий (15.x-25.x). Подробности в [docs/design.md](docs/design.md).
- Файлы не подписаны, Windows SmartScreen может предупредить при первом запуске.
